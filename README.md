# Mr. Solomon Natural Voice

Write messages, arguments, replies, and personal statements in a direct, thoughtful human voice.

This skill is used when the user wants a response that sounds like they wrote it themselves, or when any personal or persuasive writing needs to stay clear, grounded, and free of AI filler.

## What it enforces

- Simple, natural English
- Firm but respectful tone
- No em dashes
- No fake enthusiasm or cheerleading
- No empty intensifiers or corporate filler
- No unsupported absolute claims
- No invented facts or feelings
- No apologetic padding
- Clear argument structure when disagreeing

## Installation

```bash
git clone https://github.com/IceCool30/mr-solomon-natural-voice-skill.git
```

Place the folder where your agent loads skills from.

## Trigger

Use when the user asks for a reply "as if I wrote it", wants their communication style preserved, or needs a personal statement that sounds direct and human.
